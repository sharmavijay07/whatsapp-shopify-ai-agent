## Returns and refunds

Harbor & Co. accepts returns for 30 days after delivery. You can send something back if it doesn't fit. Items need to be unworn, unwashed, and with tags on. We email a free US return label. Refunds go back to the original payment method within 5 business days of the warehouse scan. Sale items are exchange-only. The Sea Salt Candle can be returned only if it is unburned. If a shirt is the wrong size, start a return the same way and we will hold the replacement size once you tell us which one.
